CURRENT SCOPE

Read first. Then build trust.

This first version reads unencrypted PC BND4 saves and displays the account profile summary. It checks basic structure and slot flags, but does not verify MD5 checksums or prove that the game will accept a save. Archive, restore, and character export are future work.
